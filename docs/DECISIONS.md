# BD-0006 미결정 사항 결정 기록

BD-0006(맥주따르기게임 기본 설계)과 REQ-0006에서 **미결정**으로 남긴 항목을 구현하면서 정한 내용이다.
수치는 모두 `src/config/balance.json`에 있으므로 코드 수정 없이 조정할 수 있다(설정 버전 `1.0.0`).

## REQ-0006에서 이어진 사항

## BD-0006에서 새로 도출된 사항

| 항목 | 결정 |
|---|---|
| 공유 방식 | **결과값만 인코딩**한다. 입력 기록 재시뮬레이션은 기기 간 부동소수 일치가 보장되지 않아 검증 수단이 되기 어렵고 URL만 길어진다. |
| 회전 애니메이션 중 판정 각도 | **보간된 각도를 시뮬레이션에도 사용**한다(화면과 판정 일치). 회전 속도가 150°/s라 5° 회전에 약 0.03초여서 입력 지연은 체감되지 않는다. |
| 높이 변경 애니메이션 | 적용한다(25cm/s). 기울기와 같은 방식으로 판정에도 보간값을 쓴다. 내용물이 담긴 잔을 움직이면 출렁임이 생기고 유효 수용 부피가 줄어든다. |
| 시뮬레이션 스텝 주기 | 1/120초. 렌더 프레임당 최대 8스텝이며, 그보다 밀리면 남은 시간을 버린다(시뮬레이션 시간 기준이라 결과에는 영향이 없다). |
| 기기 간 부동소수 편차 | **같은 기기의 결정성만 보장**한다. 기기 간 미세 편차는 허용한다. |
| 설정 변경 후 기록 호환성 | 최고 기록은 설정 버전과 함께 저장한다. 버전이 달라도 지우지 않고 "이전 밸런스 vX 기록"으로 표시하며, 더 높은 점수가 나오면 교체한다. 공유 링크는 버전이 달라도 도전할 수 있고 비교 화면에 안내를 표시한다. |
| 백그라운드 탭 | 진행 중에 탭이 가려지면 시뮬레이션과 시간 측정을 멈추고 일시정지 창을 띄운다. 멈춘 시간은 기록에 포함하지 않는다. 일시정지 중의 입력은 재개로만 쓰고 조작으로 적용하지 않는다. |
| 공유 수단 UI | Web Share API → 클립보드 복사 → 링크 텍스트 표시(수동 복사) 순으로 시도한다. |
| UI 프레임워크 | 사용하지 않는다(바닐라 TypeScript + HTML/CSS 오버레이). |
| 3D 에셋 | 모두 프로시저럴 기하(Lathe/Cylinder/Box)와 캔버스 텍스처로 만든다. 외부 모델 파일이 없다. |
| 배포 URL | Vite `base: './'`(상대 경로). 저장소 하위 경로와 사용자 지정 도메인 모두에서 설정 변경 없이 동작한다. |

## 시뮬레이션 모델 요약 (제안 → 구현)

- **좌표**: cm, 초, ml. 노즐 x=0, y=40. 잔은 축 위 바닥에서 11.2cm 지점을 잡고 회전하고 윗부분이 +x 쪽으로 기운다. 그래서 기울이면 흐름이 낮은 쪽 안쪽 벽에 비스듬히 닿고, 약 50° 이상에서는 입구 가장자리에 걸리거나 잔 밖으로 떨어진다.
- **Stream**: 매 스텝 노즐에서 Parcel(맥주·거품 액체·거품 기체)을 배출하고 중력으로 떨어뜨린다. 충돌 속도에는 낙하 높이와 초기 배출 속도가 그대로 반영된다.
- **충돌 강도** = (표면 법선 방향 충돌 속도 / 기준 속도) × 유량 보정. 액면은 정면 충돌, 잔 벽은 `sin(기울기 + 벽 각도)`만큼 약해진다.
- **층 모델**: 기울어진 원뿔대를 48조각으로 나눠 적분해 수평 액면 높이 ↔ 부피를 변환한다. 수용 부피는 가장 낮은 입구 지점까지의 부피다.
- **보존**: 배출 = 잔 + 유출 + 공중(액체), 배출 + 탄산 생성 − 방출 − 유출 = 잔 + 공중(기체). 테스트에서 매 스텝 1e-6ml 이내로 검증한다.
